# R2 „Visszajelzés” — implementációs terv

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Minden kattintás után azonnal és őszintén látszódjon, mi történik, és egy hiba miatt ne vesszen el semmi, amit a tag beírt.

**Architecture:**
- **Optimizmus:**
  - a chat-store egy `outgoing` üzenetet tart, amíg a küldés úton van;
  - a teendő-store egy `onFailed` visszahívással adja vissza a szöveget;
  - a `useRefresh` a kérést is a felső sáv átmenetén belül futtatja.
- **Őszinte hibák:**
  - egy közös `ErrorLine` komponens;
  - a Library olvasásai dobnak, ahogy a `getRadar`;
  - a poszt `processing` mezője a forrás lefoglalásából jön, és a poszt oldala addig frissül.
- **Nyomás:** két CSS-osztály (`.press`, `.press-ink`) a `globals.css`-ben, a `.lift`-hez hasonlóan, plus a mozgás és a mutató szerinti méret.

**Tech Stack:** Next.js 16.3.4, React 19.2 (aszinkron `startTransition`), Tailwind 4.2.1 (`pointer-fine:`, `motion-safe:`), tw-animate-css 1.4.0, `node --test` a `fakeDb`-vel és a render harness-szel, Playwright MCP az előnézeten.

**Spec:** `docs/superpowers/specs/2026-10-01-r2-feedback-design.md`
